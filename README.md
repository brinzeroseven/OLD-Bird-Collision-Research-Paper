**Machine Learning Research Project investigating wildlife-infrastructure collision risks across different environments.**

An independent machine learning research paper exploring how machine learning can be used to predict wildlife-vehicle and bird-turbine collisions.
The project evaluates and compares 8 supervised machine learning and deep learning approaches.
These approaches include: Random Forest, Gradient Boosting, SVM, KNN, Logistic Regression, ANN, RNN, and AdaBoost across 3 real world ecological datasets.

The projects also investigated feature correlations to identify environmental and geographical factors associated with increased collision risk.

Tech: Python, Scikit-learn, Pandas, NumPy, Matplotlib, Jupyter Notebook
